# Frontmatter conventions

Every Leto-generated artifact has typed YAML frontmatter. This is BEST_PRACTICES Law 4 (output contracts) in operational form.

## Universal fields

```yaml
created: YYYY-MM-DD
updated: YYYY-MM-DD       # only when content changed; not a touch-time
origin: human | claude    # who wrote this
```

## reader-context.md

```yaml
---
type: reader-context
created: YYYY-MM-DD
updated: YYYY-MM-DD
origin: claude            # generated by bootstrap
generated-from:
  - 80 System/Me.md
  - .claude/projects/.../memory/MEMORY.md
  - .claude/projects/.../memory/feedback_*.md
version: 1                # bump on bootstrap re-runs
---
```

## Session log (`80 System/85 Sessions/YYYY/YYYY-MM-DD-<slug>.md`)

```yaml
---
type: session
created: YYYY-MM-DDTHH:MM:SSZ
origin: claude
session-skill: leto | pm | cto | ...   # which skill ran this session
context-loaded:
  - ...
artifacts-touched:
  - ...
decisions:
  - ...
next-session-bookmark: ""
---
```

## Source (`00 Inbox/Sources/<system>/<id>.source.md` — Phase 3)

```yaml
---
type: source
origin: human                    # the inbound artifact came from a person
source-system: slack | linear | granola | gmail | calendar | notion | youtrack
source-id: <stable external ID>
source-url: <if available>
captured: YYYY-MM-DDTHH:MM:SSZ
participants: [...]
project: [[...]]
immutable: true                  # never edit; only append corrections in extract
---
```

## Extract (`00 Inbox/Sources/<system>/<id>.extract.md` — Phase 3)

```yaml
---
type: extract
origin: claude
extract-of: <path to source.md>
extract-version: 1               # bumped when reader-context or persona changes
generated-by: leto | pm | ...    # which skill produced the extract
created: YYYY-MM-DDTHH:MM:SSZ
updated: YYYY-MM-DDTHH:MM:SSZ
---
```

## Draft (`00 Inbox/Drafts/<system>/<slug>/<files>` — Phase 3)

Each draft is a folder of three files: `source.md` (immutable inbound), `extract.md` (Leto's draft reply), `decision.md` (audit trail).

`decision.md` frontmatter:

```yaml
---
type: draft-decision
origin: claude
draft-of: <path to extract.md>
target-system: slack | gmail | linear | notion
target-thread: <ID>
status: pending | approved | sent | rejected | revoked
created: YYYY-MM-DDTHH:MM:SSZ
approved-at: ""                  # populated when Vladimir flips status
sent-at: ""                      # populated after MCP execution succeeds
sent-id: ""                      # external system's confirmation ID
diff-from-draft: ""              # if Vladimir edited before approving
---
```

## TODO entries (`_claude/TODO.md`)

Per the since-markers convention (see `conventions/since-markers.md`):

```markdown
- [ ] Task description <!-- since: YYYY-MM-DD -->
```

## Notes

- All timestamps in UTC ISO 8601. Vault display layer (Dataview) handles timezone.
- `origin: claude` is mandatory for every Leto-generated file. This is the audit invariant — anything in the vault without `origin: claude` was written by Vladimir.
- Frontmatter must come first. Obsidian and Dataview both rely on this.
